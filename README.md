# 🎫 Ticket Suporte API

> API de suporte a tickets desenvolvida sem frameworks ou bibliotecas externas — só Node.js puro.

---

## 📌 Sobre

Projeto criado com o objetivo de entender na prática como funcionam APIs e os métodos HTTP (`GET`, `POST`, `PUT`, `DELETE`), sem depender de nenhum framework como Express ou Fastify.

Tudo feito na unha, utilizando apenas os módulos nativos do Node.js.

---
##Status do projeto:
> Ainda incompleto
> Alguns bugs de requisição

## 🛠 Tecnologias

- **Node.js** — runtime JavaScript
- **HTTP module** — nativo do Node.js
- Sem dependências externas
